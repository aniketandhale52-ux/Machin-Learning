
# Placement Intelligence AI

### Predictive Analytics & Career Readiness Dashboard

A professional Machine Learning web application that predicts student placement outcomes based on academic performance and student profile metrics. The system leverages a trained Scikit-Learn classification model integrated with a Flask web application to provide real-time placement predictions through an intuitive and responsive dashboard.

The project is designed for students, educational institutions, and placement cells to evaluate placement readiness using data-driven insights.

# 💡 Application Workflow

1. Enter the student's **CGPA**.
2. Provide the **IQ Score**.
3. Enter the **Profile Score**.
4. Click **Predict Placement**.
5. The trained Machine Learning model processes the inputs.
6. The application predicts whether the student is **Placed** or **Not Placed**.
7. The prediction is automatically stored in **prediction_history.csv** for future reference.
